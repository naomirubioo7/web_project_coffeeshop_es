# Triple Espresso

1. Nombre del proyecto
   Sprint 3: Página web de una cafetería – Triple Peaks

2. Descripción del proyecto y su funcionalidad
   El proyecto consiste en el desarrollo de una página web para una cafetería llamada Triple Peaks, cuyo objetivo es presentar el establecimiento, dar a conocer sus servicios y permitir que los clientes puedan realizar reservas de mesas de manera sencilla.

La página web cuenta con un diseño visual atractivo y organizado, que busca transmitir la identidad de la cafetería y ofrecer una experiencia de navegación agradable para los usuarios como el primer sorbo del cafe.

Entre sus principales funcionalidades se encuentran:

Presentación de la cafetería: muestra el nombre del establecimiento y una descripción de su propuesta de café de especialidad.
Sección de bienvenida: incluye una imagen ilustrativa del interior de la cafetería.
Información del establecimiento: presenta datos como el horario de atención y la ubicación.
Formulario de reservaciones: permite ingresar el nombre del cliente, número de comensales, fecha y hora de la reserva y correo electrónico.
Sección de contactos: proporciona información para que los usuarios puedan encontrar las redes sociales y los medios de contacto de la cafetería.
El propósito principal es facilitar el acceso a la información del establecimiento y ofrecer a los clientes una forma cómoda de solicitar una reserva.

3. Descripción de las tecnologías y técnicas utilizadas
   Para el desarrollo de este proyecto se utilizaron las siguientes herramientas y tecnologías:

HTML5: se utilizó para construir la estructura de la página web, organizar el contenido y crear los diferentes elementos, como títulos, párrafos, imágenes, enlaces y formularios.
Visual Studio Code: se utilizó como editor de código para escribir, organizar y modificar los archivos del proyecto.
GitHub: se utilizó para almacenar los archivos del proyecto en un repositorio en línea y mantenerlos organizados.
CSS3: mediante los archivos normalize.css y style.css, para definir los estilos, colores, distribución y apariencia visual de la página.
Google Fonts: para incorporar las tipografías Inter y Noto Serif
Técnicas utilizadas
Estructuración del contenido mediante etiquetas HTML.
Organización de la página en diferentes secciones.
Incorporación de imágenes y elementos visuales.
Creación de formularios con campos para recopilar información de los clientes.
Uso de enlaces para facilitar la navegación y el acceso a los contactos.
Organización de los archivos del proyecto para facilitar su edición y mantenimiento.
